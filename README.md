# 📊 Sales Outlet Management Dashboard

A modern and responsive **Sales Outlet Management Dashboard** built using **React.js** and **Tailwind CSS**. This project was developed as part of a React Developer Technical Assessment.

The application allows users to view, manage, and organize sales outlet information through a clean and user-friendly interface. The project focuses on reusable React components, responsive design, state management, and a better user experience.

# 🚀 Setup Instructions

### 1. Clone the Repository

```bash
git clone <repository-url>
```

---

### 2. Move into the Project Folder

```bash
cd sales-outlet-dashboard
```

---

### 3. Install Dependencies

```bash
npm install
```

---

### 4. Start Development Server

```bash
npm run dev
```

---

### 5. Build for Production

```bash
npm run build
```

# 📋 Assumptions Made

- Authentication is not implemented since it was not required.
- Outlet data is stored locally using a JSON file.
- Data updates are maintained only during the current session.
- Internet connection is not required after dependencies are installed.
- The application focuses on frontend functionality only.

---

# ⚠ Known Limitations

- No backend or database integration.
- Login does not perform real authentication.
- Added or edited outlet data is not permanently saved after page refresh.
- Search and filtering functionality are not included.
- Multiple users and user roles are not supported.
- API integration has not been implemented.
